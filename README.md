# 🍚 집밥 레시피

가지고 있는 재료를 기준으로 오늘 만들 레시피를 추천해 주는 웹 앱입니다.

## 실행 방법

```bash
cd ~/recipe
npm start
```

브라우저에서 **http://localhost:3000** 을 엽니다.
터미널에 표시되는 `같은 Wi-Fi` 주소로 접속하면 휴대폰에서도 쓸 수 있습니다.
(외부 패키지 설치 없이 Node.js만 있으면 됩니다.)

## 기능

- **냉장고**: 재료 등록(카테고리, 수량, 구매 일자, 소비 기한, 냉장/냉동/실온). 날짜는 `YYYY/MM/DD`로 입력합니다(숫자 8자리만 쳐도 슬래시가 자동으로 들어가고, 📅 버튼으로 달력에서 고를 수도 있어요). 날짜를 모르면 「모름」에 체크하면 되고, 소비 기한을 모르는 재료는 「기한 모름」으로 표시되어 목록 맨 뒤에 놓입니다. 소비기한 임박순·최근 구매순·이름순으로 정렬하고, 보관 방법이나 카테고리로 필터링할 수 있습니다. D-day 배지는 3일 이내면 주황, 지나면 빨강으로 표시됩니다.
- **레시피**: 필요한 재료(필수/선택), 요리 순서, 출처(URL이면 링크), 메모를 등록합니다. 이름이나 재료로 검색할 수 있습니다.
- **이번 주**: 오늘의 추천이나 레시피 상세에서 「이번 주에 담기」로 이번 주 먹을 레시피를 모아 둡니다. 요일을 정하거나 먹은 것을 체크할 수 있고, 아직 안 먹은 레시피에 부족한 재료는 🛒 장보기 목록으로 모아서 보여 줍니다.
- **오늘의 추천**: 보유 재료 일치율과 소비기한 임박 정도로 점수를 매겨 추천합니다. 보유/임박/부족 재료를 보여 주고, 「다른 추천 보기」로 상위 5개 안에서 다른 추천을 볼 수 있습니다.

### 추천 점수
- 필수 재료 보유 비율 × 70
- 레시피에 쓰이는 임박 재료 1개당: D-0~1 +15, D-2~3 +10, D-4~7 +5
- 선택 재료 1개 보유당 +2
- 기한이 지난 재료도 기본으로 추천에 포함하며(D-0~1과 같은 +15), ⛔ 표시로 상태를 확인하도록 알려 줍니다. 「기한 지난 재료도 추천에 포함」 체크를 끄면 제외됩니다.
- 소비 기한을 모르는 재료는 보유한 것으로 보되 임박 보너스는 없습니다.
- 「양념·소스는 기한이 지나도 그대로 사용」(기본 켜짐): 카테고리가 양념·소스인 재료는 기한이 지나도 ⛔ 기한 지남으로 표시하지 않고 일반 보유 재료로 봅니다(보너스 없음). 냉장고 목록에서도 빨간 표시 대신 회색으로 보입니다.
- 재료 이름은 띄어쓰기를 무시하고, 한쪽이 다른 쪽을 포함하면 같은 재료로 봅니다(예: "돼지고기 앞다리" = "돼지고기"). 단, 짧은 쪽이 한 글자일 때는("파"와 "양파") 이름이 정확히 같아야 합니다.
- 동의어(계란=달걀, 쇠고기=소고기, 케찹=케첩, 파=대파, 소고기다시다=조미료 등)는 같은 재료로 봅니다. 한 글자 동의어("파")는 이름 전체가 "파"일 때만 적용되어 양파·쪽파와는 섞이지 않습니다. 동의어를 더하려면 `app.js` 위쪽의 `SYNONYMS` 목록에 한 줄을 추가하세요.
- 이름이 겹쳐도 다른 재료(순두부 ≠ 두부)는 `SEPARATE_NAMES` 목록으로 구분합니다.

## 데이터

모든 데이터는 이 폴더의 `data.json`에 자동 저장됩니다. 이 파일을 복사해 두면 그대로 백업이 됩니다.
첫 실행 때는 예시 레시피 3개가 들어 있는 상태로 만들어집니다.
